# EcoPick

Aplikasi mobile untuk menjemput sampah terpilah dari depan pintu dan mengubahnya menjadi poin.

## Fitur
- Scan sampah dengan kamera dan AI
- Request pickup dan tracking kurir
- Eco-Wallet (poin) dan impact tracker
- Riwayat pickup
